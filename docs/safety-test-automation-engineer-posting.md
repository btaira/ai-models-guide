# Safety Test and Automation Engineer

> Fill in the bracketed fields before posting. Internal reference for interviewers:
> [`safety-test-automation-engineer-role-description.md`](safety-test-automation-engineer-role-description.md).

The Compliance Team is an agile and diverse group working across all core hardware
engineering product lines. We're looking for a test engineer and developer to perform
product safety testing and to maintain and grow AutoTherm, our automated safety-test
application. You'll write Python that controls real lab equipment, and you'll work side by
side with the test engineers who use your software every day.

## Responsibilities

- Perform product safety tests to IEC 62368-1, including input, heating (thermal),
  dielectric withstand, touch current, ground bond, and abnormal/fault-condition tests
- Improve AutoTherm and extend automation beyond thermal testing to dielectric withstand,
  touch current, and ground bond tests
- Fix bugs and build features in a Python/Tkinter desktop application
- Write and maintain code that communicates with lab instruments over the network using
  SCPI (power sources, power meters, temperature recorders, environmental sensors)
- Maintain the test pass/fail logic and the generation of test-report tables used in
  certification submissions
- Add automated tests and hardware simulators, so more of the code can be tested without
  lab equipment
- Move test data into a SQL database to make results traceable and searchable
- Package and release the application for Windows and macOS
- Help lab users troubleshoot connection and setup problems
- Use AI tools to build skills and tools that improve the team's workflow

## Minimum qualifications

- BS in Electrical Engineering, Computer Engineering, or Computer Science (or equivalent
  experience), with 3+ years of related experience
- Proficiency in Python scripting and development
- Experience automating test equipment, preferably with SCPI, VXI-11, GPIB, or PyVISA
- Proficiency hand-soldering small surface-mount and through-hole components, using a
  microscope when needed (for example, to set up fault conditions)
- Working knowledge of Git and SQL
- Basic networking knowledge: IP addresses and ports, TCP connections, timeouts, and common
  connection errors
- Excellent written and verbal communication skills

## Preferred qualifications

- Knowledge of IEC 62368-1 and product safety compliance testing
- Experience with oscilloscopes, multimeters, programmable power supplies, and safety
  testers (hipot, ground bond, touch current)
- Familiarity with high-voltage lab safety practices
- Experience using AI coding agents (e.g., Codex, GitHub Copilot, Cursor) to speed up
  development, with rigorous review of AI-generated code
- Building AI skills or tools that a team can use
- GUI development, ideally Tkinter/ttk
- Data visualization with matplotlib
- Network programming: Python sockets, handling partial responses, and retry and reconnect
  logic
- Automated testing with pytest, including mocking or simulating hardware
- XML processing (lxml, XPath) or experience generating Word/Office documents
